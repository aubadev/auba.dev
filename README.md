# Auba Dev Portfolio

Eine moderne, interaktive Portfolio-Website mit dynamischem Design und innovativer Benutzererfahrung für 2025.

## 🚀 Technologien

- React mit TypeScript
- Tailwind CSS für Styling
- Framer Motion für Animationen
- Responsive Design
- Interaktive UI-Elemente
- Performance-optimiertes Frontend

## 📋 Voraussetzungen

- Node.js (Version 18.x oder höher)
- npm (Version 8.x oder höher)

## 🔧 Installation

1. Repository klonen:
   ```bash
   git clone https://github.com/aubadev/auba.dev.git
   cd auba.dev
   ```

2. Abhängigkeiten installieren:
   ```bash
   npm install
   ```

## 🏃‍♂️ Starten der Anwendung

### Entwicklungsumgebung

Um die Anwendung im Entwicklungsmodus zu starten:

```bash
npm run dev
```

Die Anwendung ist dann unter `http://localhost:5000` erreichbar.

### Produktionsversion erstellen

Um einen Produktionsbuild zu erstellen:

```bash
npm run build
```

Die kompilierten Dateien werden im Verzeichnis `dist` abgelegt.

### Produktionsversion starten

Um die gebaute Produktionsversion zu starten:

```bash
npm run start
```

## 🧩 Projektstruktur

```
portfolio/
│
├── client/              # Frontend-Dateien
│   ├── src/
│   │   ├── assets/      # Bilder, Schriften, etc.
│   │   ├── components/  # React-Komponenten
│   │   ├── hooks/       # Benutzerdefinierte React-Hooks
│   │   ├── lib/         # Hilfsfunktionen und Konstanten
│   │   └── pages/       # Seitenkomponenten
│   │
│   └── index.html       # HTML-Template
│
├── server/              # Backend-Dateien (Express)
│
├── dist/                # Kompilierte Produktionsversion
│
└── README.md            # Projektdokumentation
```
